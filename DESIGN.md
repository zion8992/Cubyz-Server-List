## The Idea
Make the `src/cmd` start a webserver that renders a list of servers. 
These servers will be generated from `servers.json`.

## Web Interface
The web interface will have a list of servers. Everything entirely static. Use JS to ping servers and get **version**, **description**, **gamemodes**, **languages**, whether or not the server **requires mods to play**, etc..

## API
This can either be a bunch of JSON files generated of `servers.json` (painfull and time-consuming). 
Or, it can be a series of endpoints that return JSON, generated by the webserver on the moment from `servers.json`
