Server admins can create an XML feed of their server announcements. When players head to the 'Announcements' tab of a server, the XML feed is loaded and show to the player.

Fusion is a python script that allows you to manage, create, update and delete announcements/posts for your server.

Rules

Welcome to the community server list! By using this server list, you agree to follow all rules below. These rules apply to both server operators/administrators and users of this list.



Enforcement

Failure to follow these rules may result in a ban from the server list. Ban evasion, including creating new accounts, using alternate identities, or circumulating a ban in any way, is strictly prohibited and will result in a permanent ban with no possibility of appeal.



Rules for Server Operators

1. Free to Join
All servers must be free to join. Servers may not require an upfront payment, subscription, or any mandatory fee for access.


2. Pay-to-Win is Allowed
Pay-to-win (P2W) servers are permitted on this list. However, the server listing must clearly indicate that it is a pay-to-win server in the first ten lines of the server description


3. No NSFW Content
Servers containing NSFW (Not Safe For Work) content, including sexual, pornographic, or otherwise explicitly adult material, are not allowed on this server list.


4. Content Warnings Required
If your server contains or references any of the following, you must specify it clearly in the first five lines of your server description:


  • Drugs or drug use
  • Alcohol or alcohol consumption
  • Tobacco or smoking
  • Gambling or betting mechanics
  • Strong/profane language
  • Violence or graphic content
  • Any other potentially sensitive or mature content

Failure to properly disclose sensitive content will result in removal of your listing and possible ban.


5. Accurate Descriptions and Data
Server descriptions and data (languages) must be accurate and not misleading. Do not use deceptive descriptions to attract players. You are allowed to use clickbait titles.


6. No Malicious Servers
Servers that distribute malware, attempt to steal user data, or otherwise harm players are strictly prohibited. Operators found running malicious servers will be permanently banned.


7. Keep Listings Updated
If your server goes offline permanently or changes significantly (e.g., new sensitive content is added), update your listing or remove it promptly.



Rules for Server List Users

1. No Harassment or Abuse
Do not harass, threaten, or abuse other users, server operators, or server list staff. This includes hate speech, personal attacks, and targeted harassment.


2. No Spamming
Do not spam the server list with duplicate submissions, fake reviews, or irrelevant content. This includes mass-downvoting or review-bombing servers.


3. No Manipulation
Do not attempt to manipulate server rankings, ratings, votes or visibility through artificial means (bots, vote manipulation, fake accounts, etc.).


4. Respect Content Warnings
Respect the content warnings and tags provided by server operators. If you join a server with disclosed sensitive content, you accept that disclosure by choosing to join.


5. Report Responsibly
If you report a server or user, do so "in good faith". False or malicious reports are considered abuse of the system and may result in a ban.


6. No Ban Evasion
If you have been banned from the server list, you may not create a new account or use another identity to regain access. Ban evasion will result in a permanent ban.


Reporting Violations

If you encounter a server or user that violates these rules, please report it to the server list moderators. Provide as much detail as possible, including evidence if available.
